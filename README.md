# bookbot

BookBot is my first [Boot.dev](https://www.boot.dev) project!

- The script accepts a user input as a path to a text file

- The script then prints 3 things as a report
    1. the File that being analized
    2. The number of words the text file has
    3. the amount of each char/space/symbol presented, in order, from the highest to the lowest.
